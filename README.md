# Komputasi Numerik

Repository ini berisi dokumentasi dan implementasi Python untuk dua topik komputasi numerik:

1. Penyelesaian Sistem Persamaan Linear (SPL) tiga variabel dengan metode Gauss-Jordan dan pemilihan pivot parsial.
2. Penyelesaian persamaan nonlinear satu variabel dengan metode Bisection.

## Cara menjalankan notebook

1. Buka https://colab.research.google.com/.
2. Pilih **File → Open notebook → GitHub**, lalu masukkan URL repository, atau unggah file `.ipynb` dari komputer.
3. Jalankan setiap cell dari atas ke bawah menggunakan tombol ▶ atau `Shift + Enter`.
4. Baca penjelasan Markdown sebelum menjalankan cell kode.
5. Setelah disesuaikan dan diuji, simpan notebook kembali ke GitHub melalui **File → Save a copy in GitHub** atau unggah file `.ipynb` terbaru ke repository.

## Catatan akademik

Metode Bisection pada notebook ini menyelesaikan persamaan nonlinear satu variabel berbentuk `f(x) = 0`. Metode Bisection standar tidak langsung menyelesaikan sistem nonlinear yang mempunyai beberapa variabel. Apabila dosen memberikan sistem nonlinear multivariabel, mintalah penegasan mengenai bentuk soal atau metode yang diminta.
